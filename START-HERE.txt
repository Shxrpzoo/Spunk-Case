SPUNK CASES v2 — THREE CASES, 108 CARDS

UPDATING YOUR EXISTING WORKING WEBSITE

1. Extract Spunk-Cases-V2.zip.
2. Open spunk-cases/database/UPDATE-V2.sql in Notepad.
3. Copy ALL of the SQL text in that file.
4. In your EXISTING Supabase project, open SQL Editor, paste the SQL text into
   a new query, and click Run. Do not type the filename into SQL Editor.
   The script keeps existing players, passwords, Nuggets, cards, sessions,
   rewards and history. It adds the new cards and effect/discovery storage.
   It is safe to rerun. A successful SQL run may say "No rows returned".
5. Update your GitHub repository with ALL files and folders INSIDE spunk-cases.
   package.json and vercel.json must be at the repository root.
   Upload the extracted files, not the ZIP itself. Include public/assets/items:
   those are all 108 web-optimized card pictures.
   GitHub's browser uploader may need several batches for this many files;
   GitHub Desktop can commit the entire update together.
6. Keep your existing working Vercel environment variables and Supabase project.
   DATABASE_URL stays pointed at the SAME database.
   APP_ORIGIN stays https://spunkcase.vercel.app.
   Keep INVITE_CODE and ADMIN_PASSWORD_HASH. Leave USE_LOCAL_DB unset.
7. Deploy the updated main branch in Vercel. Build: npm run build.
   Node.js: 22.x. Output directory: default Next.js.
8. Sign in using your existing name and passcode. Check all three cases and
   the Leaderboard tab. Your saved progress remains in Supabase.

Optional SQL check after Step 4:
SELECT id,name,price FROM spunk.cases ORDER BY price;
SELECT count(*) FROM spunk.items;
Expected defaults: Basic 20, Ash 100, Semen Satchel 150; 108 cards.

This package has been built and tested locally. It has NOT been pushed to your
GitHub account or applied to your live Supabase database by the assistant.

Details, rarities, odds and local development: README.md and CATALOG.md.
